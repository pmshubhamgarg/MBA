# MBA Notes

Organized class notes, session summaries, and resources for each MBA subject.

## How this is organized

Each **subject** has its own section in the sidebar. Within each subject, content is organized by **session** (class number). Each session page includes:

- Key topics covered
- Session notes and summaries
- Links to relevant resources (readings, slides, case studies)

Browse subjects from the sidebar or use the search bar to find specific topics.
